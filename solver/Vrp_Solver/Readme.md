INTRO
This project implements a solution to the Vehicle Routing Problem (VRP) using various optimization techniques, including Tabu Search, Variable Neighborhood Search (VNS), and Clarke-Wright Algorithm. It reads input data from the given file, constructs a VRP model, and solves it using the algorithms mentioned above. The solution is written to an output file, which includes the total cost and the optimal routes for the vehicles. We 've experimented with various optimization methods, some of which didn't produce the best outcome and are commented out. With more time, we could further refine these techniques and fine-tune the heuristics to strike a better balance between intensification and diversification.

HOW TO RUN
To run the code, run main.py.
